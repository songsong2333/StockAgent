# 纳指+新能源 组合信号 & 金融危机预警

组合 = **纳指50%(核心,轻择时防崩) + 新能源50%(卫星,v2趋势进攻)**;创业板/科创50 作为监控。
纳指默认持有、跌破 MA200 才避险(防崩);新能源严格趋势(强势才杀入);并用**美债收益率曲线倒挂**作金融危机预警。回测(2016-2026): 组合年化 +14.1%、回撤 -14.8%、9/10 年正收益。

## When to Use

用户问及以下任一时触发:
- "今天/现在的信号、组合信号、进出场"
- "纳指该不该持有/会不会崩、新能源/创业板/科创50 该不该进"
- "市场强势吗、进场还是观望、杀入时机"
- "有没有金融危机风险、美债倒挂了吗、要不要避险"

## 执行步骤

1. 切到项目根并用虚拟环境运行 CLI(会自动采集最新指数 60min 数据,新浪源约几秒):
   ```bash
   cd /Users/jojo/coding/stock_agent
   .venv/bin/python scripts/run_entry_exit.py
   ```
   - 若不想联网采集、用现有缓存数据,加 `--no-collect`。
   - 若 `.venv` 不可用,退回 `python scripts/run_entry_exit.py`(需已装依赖)。

2. 直接把 CLI 输出的信号块原样呈现给用户(含 🟢/🔵/⚪/🛡️/🔴 图标、收盘价、MA200 位置、ER 值、移动止损位、🚨美债倒挂预警)。

3. 用 1~2 句中文解读当前状态(见下),**不要夸大、不要给买卖承诺**。

## 输出解读(转述给用户时遵守)

| 状态 | 含义 | 该怎么说 |
|---|---|---|
| 🟢 杀入 | (新能源/成长板)强势+突破+ER+放量 | 强势确认,信号提示杀入 |
| 🔵 持有 | 当前在场内 | 继续持有,跌破"移动止损位"才离场 |
| ⚪ 观望 | 不强势/震荡 | 现在不是强势时刻,等信号,别硬进 |
| 🛡️ 避险 | (纳指)跌破 MA200 | 纳指趋势破位,避险观望,收复 MA200 再进 |
| 🔴 刚离场 | 最新bar触发离场 | 已离场,转观望 |

**🚨 美债曲线倒挂**: 若出现,说明美债 10y-2y 利差<0——历史上每次美国衰退/金融危机前都倒挂,是**领先预警**(提前数月到一年),提示降低纳指风险敞口;但它**不精确择时**(危机爆发时曲线会重新变陡),不要当作立刻清仓指令。

## 诚实护栏(重要)

- 组合是**低频高确定性思路**,不是每笔必赚;进攻板胜率约50%,靠盈亏比≈3 获利。
- 纳指防崩用约 2.7pp 年化换回撤减半(-55%→-22%);它躲的是大崩,平时会小幅跑输死拿。
- 历史验证含牛熊,但**不保证未来**;务必附"非投资建议"。
- 采集若失败,CLI 用缓存数据并在日志提示,转述时说明数据截止时间(as_of)。
- 不要替用户下单,只呈现信号与解读。
