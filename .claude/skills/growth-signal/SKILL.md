# 成长板确定性进攻信号

只在市场强势时给出"杀入创业板/科创50"的进攻信号;不强势就明确让助手告知"观望"。**不做防守切换、不预测顶部、不频繁交易**。

## When to Use

用户问及以下任一时触发:
- "今天/现在的进攻信号、成长板信号"
- "创业板 / 科创50 该不该进、能不能杀入"
- "市场强势吗、现在是进场时机吗、进场还是观望"
- "查一下信号"

## 执行步骤

1. 切到项目根并用虚拟环境运行 CLI(会自动采集最新指数 60min 数据,新浪源约几秒):
   ```bash
   cd /Users/jojo/coding/stock_agent
   .venv/bin/python scripts/run_entry_exit.py
   ```
   - 若不想联网采集、用现有缓存数据,加 `--no-collect`。
   - 若 `.venv` 不可用,退回 `python scripts/run_entry_exit.py`(需已装依赖)。

2. 直接把 CLI 输出的信号块原样呈现给用户(含 🟢/🔵/⚪/🔴 图标、收盘价、日线强势✓/✗、ER 值、持仓时的移动止损位)。

3. 用 1~2 句中文解读当前状态(见下),**不要夸大、不要给买卖承诺**。

## 输出解读(转述给用户时遵守)

| 状态 | 含义 | 该怎么说 |
|---|---|---|
| 🟢 杀入 | 日线强势+60min突破+ER达标 | 强势确认,信号提示下根开盘杀入 |
| 🔵 持有 | 当前在场内 | 继续持有,跌破"移动止损位"才离场 |
| ⚪ 观望 | 不强势/震荡 | 现在不是强势时刻,等信号,别硬进 |
| 🔴 刚离场 | 最新bar触发离场 | 已离场,转观望 |

## 诚实护栏(重要)

- 信号是**低频高确定性思路**,不是每笔必赚;胜率约50%,靠盈亏比≈3 获利。
- 历史验证窗口含牛市也含熊市,但**不保证未来**;务必附"非投资建议"。
- 采集若失败(新浪偶发),CLI 会用缓存数据并在日志提示,转述时说明数据截止时间(as_of)。
- 不要替用户下单,只呈现信号与解读。
